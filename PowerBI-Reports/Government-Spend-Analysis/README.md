# Connecticut Government Expenditures – Power BI Dashboard 
A full end-to-end BI project analyzing government spending using the 
State of Connecticut Expenditures dataset. 
##       
Project Overview 
This dashboard provides a financial and operational view of 
government 
payments, vendors, departments, and spending trends. 
The project demonstrates: - Data modeling (star schema) - Power Query transformations - DAX measures - KPI design - Time intelligence - Vendor & department analysis --- 
##             
Data Model 
**Fact Table** - FactPayments (Payment Amount, Amount, Dates, Keys, Identifiers) 
**Dimensions** - DimVendor - DimDepartment - DimProgram - DimService - DimAccount - DimFund - DimPaymentMethod - DimDate --- 
##     
Key KPIs - Total Spend - Average Payment - Transaction Count - Top Vendor Spend - Spend by Department 
- Monthly & Yearly Trends - YoY Growth - Running Total Spend --- 
##      
Dashboard Pages 
1. **Executive Overview** 
2. **Vendor Analysis** 
3. **Department Analysis** 
4. **Time Intelligence** --- 
## 🛠 Tools Used - Power BI Desktop - Power Query - DAX - Excel/CSV - Data Modeling (Star Schema) ---
